# 初代 (2024-05-20~23)
## ver1
### 一番最初のモチベ
配信ツールを作るのが好きであり、プログラミングと配信をかけあわせておもしろいコンテンツを作ろうと思っていた。普通に人気の生主になろうと思っていた。
最初ネウロ様に憧れた。今でもそうだけど。

### システム
https://github.com/boxfish-jp/aiVtuberBasic/commit/4b2613b71b4da326391d0b6a575744db04b40c2c
コメントに対して、AIが逐次反応するシステムを作った。
flaskでrest APIを立てて、配信ツールからコメントの文字列を送ってもらって、AIが返答を考え、出力された文字列をVoiceVoxで音声合成する。
音声ファイルはpythonのsounddeviceで再生していた。
ちなみに、apiはこのころgeminiが出始めで、API料金が高いし、ドキュメントの整備も進んでいなかったので、chat bisonを使っていた。

### 最初のシステムの問題点
コメント読み上げとAIの返答が同時に行われて、カオスな配信になる。
自分がしゃべりたいときに被ってしまう。
視聴者がふぐおに質問をしているのに、AIが喋ってしまい、ふぐおが非常に喋りづらかった。
このころ、AI Tuberが不適切発言をして大炎上してたので、そういう対策が必要だと思った。

## 初代修正
### システム
https://github.com/boxfish-jp/aiVtuberBasic/commit/f343bd43e4ce44477f36afb95f2bb90f385a2afc
これ答えなくていいというのをコントローラー(xboxコン)でコントロールできるようにした。
xboxコンのボタンを押すとrest apiのリクエストが発火するようにして、interruptリクエストが来ると、現在生成されている音声が全て再生されなくなるという機能を付け足した。
しかし、これは現在まさに音がなっている音声ファイルには、効力がなく、再生を止めることはできないので、あんまり使い心地が良くなかった。
