# なぜそんなシステムを作った?
- 配信上の悩みを解決するため。(建前)
- AI Tuberで雑談配信じゃない運用を使用と思った場合に、役割をふるしかなかった。
  - AIは基本的にこういうことが話したいとか、こういうことを今考えているんだよね。といった意志みたいなものがない。なので、全部何かしらのことについて、コメントをするといった感じになる。なので、聞き上手ではあるけど、自分から会話をエスコートすることはできない。
  - いちおう、どんなことをしてみたい？とかした？といった話題をハルシネーションで作れるけど、嘘を聞きたいと思う人っていないと思うし、聞いていても面白いものはないのかな。
  - なので無から会話の話題を生み出すのって難しい。というか人間でもそう。関係性とかポジションがあって、初めて会話が生まれる。関係性とポジション自体がよくわからない全くの他人って、天気の話くらいしかできない。出身地の話とか最近忙しいですかとしてきた経験ベースの話ってAIには難しい。なので、ポジションとか仕事をふることにした。
  - ポジションをふることで、AIと話したい話題をこちらから提供できたり、その設定上話しかける必要のある会話ができたりする。
  - 意思を頑張ってもたせる(機嫌パラメーターの導入)といったことをするのもいいけど、私はロボットは感情がないからこそ面白いやろっていう人なので、そっちのアプローチは取らなかった。人間に近づけるのが目標ではなくて、SFっぽさの追求の方が優先。
